# Stick Fort promo kit

Everything here was made from real screenshots of the game, captured by running it. This folder sits next to the game folder, so none of it is deployed with the game.

| Folder | What is inside |
|---|---|
| art/ | Key art (with and without tagline), web banner 1920x480, store capsules (920x430, 462x174), itch.io cover 630x500, OG share image 1200x630, feature sheet |
| social/ | X post 1600x900, X header 1500x500, 4 Instagram squares 1080x1080 (carousel), Instagram/TikTok story 1080x1920, YouTube thumbnail 1280x720 |
| video/ | 25 s trailer (1280x720 MP4, silent), two looping GIFs (gameplay, boss) |
| screenshots/ | 8 store screenshots 1920x1080, plus 4 battle shots with the HUD hidden |
| icons/ | favicon.svg, favicon.ico, 16/32/48/192/512 PNG, apple-touch-icon (180) |
| store-copy.md | Taglines, short and long descriptions, feature bullets, press blurb, captions |
| og-meta-snippet.html | Share-preview and icon tags for index.html (not wired in yet) |

The trailer has no sound, so add music in your editor if you want it.
